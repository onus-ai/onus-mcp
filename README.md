# onus-mcp

MCP server reference implementation of the [Onus Intent Spec](https://github.com/onus-ai/onus-intent-spec).

🚧 **Work in progress.** Code lives in a private monorepo while v0.1 of the spec stabilizes; this repo will be populated when the implementation is ready for external review.

In the meantime, see the [spec README](https://github.com/onus-ai/onus-intent-spec) for the data model and evaluator semantics this package implements.
